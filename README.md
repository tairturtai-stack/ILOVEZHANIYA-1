# ILOVEZHANIYA — запуск

Файлы: server.mjs, watch.html, package.json (все в корне проекта).

## Replit
1. Создайте Repl «Node.js», загрузите три файла.
2. Нажмите Run (команда: node server.mjs или npm start).
3. В консоли должно появиться: «ILOVEZHANIYA на порту 3000».
4. Откройте адрес Repl (Webview или «Open in new tab»), создайте комнату,
   отправьте ссылку второму человеку.

## Компьютер
npm install && npm start  →  http://localhost:3000

Нужен HTTPS (Replit даёт его сам): иначе не работает микрофон.
Загрузка файлов: до 1 ГБ (переменная MAX_UPLOAD_MB).
